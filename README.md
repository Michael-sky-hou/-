# 基于链表的动态内存管理器

## 题目背景

操作系统需要管理一段连续内存。当程序申请内存时，系统从空闲区域中选择一块合适的空间；当程序释放内存时，系统需要回收空间，并合并相邻的空闲区域。

请使用 C 语言实现一个简化的动态内存管理器。程序不需要真正分配指定大小的内存，而是通过数据结构模拟内存块的申请、释放、查询和紧凑整理过程。

> **提示**：本题重点不在于调用 `malloc` 管理一块真实的大数组，而在于用链表维护“已分配区间”和“空闲区间”的状态。

## 一、内存模型

系统管理一段大小为 `M` 的连续模拟内存，地址范围为：

```text
[0, M - 1]
```

每个内存块使用起始地址 `start` 和块大小 `size` 表示，其占用地址范围为：

```text
[start, start + size - 1]
```

程序启动时，整段内存均为空闲状态，即只有一个空闲块：

```text
start = 0, size = M
```

每个已分配内存块都有一个唯一名称 `id`。地址与大小均使用十进制整数表示。

## 二、功能要求

### 2.1 申请内存

```text
ALLOC id size
```

为编号为 `id` 的对象申请大小为 `size` 的连续内存，采用最佳适应算法（Best Fit）：

1. 在所有能够容纳 `size` 的空闲块中，选择大小最小的空闲块。
2. 如果存在多个大小相同的候选块，选择起始地址最小的空闲块。
3. 从选中空闲块的低地址一端分配内存。
4. 分配后，修改或删除对应的空闲块。

申请成功时输出：

```text
ALLOCATED id start
```

如果 `id` 已经存在，输出：

```text
ALLOC_FAILED id DUPLICATE
```

如果没有足够大的连续空闲块，输出：

```text
ALLOC_FAILED id NO_SPACE
```

> 即使空闲内存总量足够，但没有一块连续区域能够满足申请，申请仍然失败。

### 2.2 释放内存

```text
FREE id
```

释放编号为 `id` 的已分配内存块。释放后，应将该区域插入空闲链表，并立即合并所有地址相邻的空闲块。

```text
[0, 9]、[10, 14]、[15, 19]  ->  [0, 19]
```

释放成功时输出：

```text
FREED id start size
```

如果 `id` 不存在，输出：

```text
FREE_FAILED id NOT_FOUND
```

### 2.3 查询内存块

```text
QUERY id
```

查询成功时输出：

```text
BLOCK id start size
```

如果不存在，输出：

```text
BLOCK_NOT_FOUND id
```

### 2.4 内存紧凑整理

```text
COMPACT
```

将所有已分配块依照当前起始地址从小到大的顺序移动到内存低地址端，消除块与块之间的空隙。整理时必须满足：

- 已分配块之间的相对顺序不变；
- 第一个已分配块的新起始地址为 `0`；
- 后续内存块紧接在前一个内存块之后；
- 整理完成后，最多只能存在一个空闲块；
- 只有起始地址发生变化的块才算被移动。

输出第一行为：

```text
COMPACTED k
```

其中 `k` 表示实际发生移动的内存块数量。随后按照整理后的地址顺序，输出每个被移动块的信息：

```text
id old_start new_start
```

如果没有任何块需要移动，则只输出：

```text
COMPACTED 0
```

### 2.5 输出内存状态

```text
DUMP
```

首先输出已分配块数量及各块信息，再输出空闲块数量及各块信息。两类内存块均按照起始地址从小到大排列：

```text
ALLOCATED_BLOCKS k
id start size
...
FREE_BLOCKS t
start size
...
```

## 三、输入格式

第一行包含两个整数 `M` 和 `Q`，分别表示模拟内存总大小和命令数量：

```text
M Q
```

接下来 `Q` 行，每行是一条命令：

```text
ALLOC id size
FREE id
QUERY id
COMPACT
DUMP
```

## 四、输出格式

按照各命令的要求输出执行结果。所有输出中的地址均为十进制整数，不得输出题目未要求的提示信息。

## 五、输入约束

- `1 <= M <= 1,000,000,000`
- `1 <= Q <= 5,000`
- `1 <= size <= M`
- `1 <= id` 长度 `<= 15`
- `id` 只包含大小写英文字母、数字和下划线。输入命令格式保证合法。

## 六、样例

### 样例输入

```text
30 12
ALLOC A 8
ALLOC B 6
ALLOC C 5
FREE B
ALLOC D 4
DUMP
ALLOC E 7
FREE A
ALLOC F 9
COMPACT
ALLOC F 9
DUMP
```

### 样例输出

```text
ALLOCATED A 0
ALLOCATED B 8
ALLOCATED C 14
FREED B 8 6
ALLOCATED D 8
ALLOCATED_BLOCKS 3
A 0 8
D 8 4
C 14 5
FREE_BLOCKS 2
12 2
19 11
ALLOCATED E 19
FREED A 0 8
ALLOC_FAILED F NO_SPACE
COMPACTED 3
D 8 0
C 14 4
E 19 9
ALLOCATED F 16
ALLOCATED_BLOCKS 4
D 0 4
C 4 5
E 9 7
F 16 9
FREE_BLOCKS 1
25 5
```

## 七、样例说明

第一次执行 `ALLOC F 9` 时，空闲块分别为起始地址 `0`、大小 `8`；起始地址 `12`、大小 `2`；起始地址 `26`、大小 `4`。空闲内存总量为 `14`，但最大的连续空闲块只有 `8`，因此申请失败。

执行 `COMPACT` 后，`D` 从 `8` 移动到 `0`，`C` 从 `14` 移动到 `4`，`E` 从 `19` 移动到 `9`。此时末尾形成一个大小为 `14` 的连续空闲块，因此第二次申请 `F` 成功。
